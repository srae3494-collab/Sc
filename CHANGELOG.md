# Changelog

## V2.2 (crosshair overhaul)
- Rebuilt the crosshair with a neon-tube style: colored body, white core, glow halo, and dark outline.
- Replaced the stepped 8-color switching with smooth, continuous color flow.
- Added color themes: Neon, Rainbow, Toxic, Fire, Ice, Royal.
- Added the Tactical layout (T-shape) and rebuilt the existing layouts.
- Fixed diagonal arm placement and rotation for Cyber X / Rainbow Star.
- Outer ring is now a spinning gradient stroke (arcs in Neon Vortex) with a glow layer.
- Added orbiting dots (Orbital), a rotating star (Rainbow Star), and a breathing ring animation.
- Added a click bloom pulse and toggles for color flow, spin / orbit, and click pulse.
- Model and theme buttons now show the current selection.

## V2.1
- Added a scrollable settings panel.
- Added separate RGB colors for crosshair arms and a rotating multi-color palette.
- Added diagonal crosshair arms for the Cyber X and Rainbow Star layouts.
- Added glow-level and opacity controls.
- Added Low, Medium, High, Ultra, and Performance lighting presets.
- Added session-only Save and Load configuration controls.
- Added Reset All Settings.
- Added close control and cleanup for render / drag connections.
- Added restoration of captured Lighting values and existing post-effect enabled states.

## Notes
- Runtime behavior has not been verified across Roblox Studio versions, devices, or third-party environments.
- The project is intended for LocalScript use in an experience the user owns or is authorized to modify.
